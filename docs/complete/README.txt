СОДЕРЖАНИЕ ОСНОВНОГО ДОКУМЕНТА

- назначение, состав и границы Helpify и MyDealer;
- техническое задание и критерии готовности;
- функциональные спецификации и подробные варианты использования;
- роли заказчика, исполнителя, покупателя, вендора и администратора;
- сайты, web-приложения, административные интерфейсы и UI/UX;
- PHP 7.4, Laravel 8, HTML5, CSS3, JavaScript, MySQL 8 и Redis 6;
- Ubuntu Server 20.04 LTS, Nginx 1.18, Docker Engine 20.10 и Docker Compose 1.29;
- REST API, Bearer-аутентификация, коды ошибок и OpenAPI 3.0.3;
- Android/Kotlin и iOS/Swift;
- модели данных, ER-диаграммы, миграции и сроки хранения;
- OWASP Top 10:2021, API Security Top 10:2019, Mobile Top 10:2016,
  ASVS 4.0.3, MASVS 1.4.0 и MSTG 1.2;
- защита персональных данных и права субъектов;
- DevOps, Git, патчи, развертывание, резервное копирование и мониторинг;
- тестирование, приемка, выпуск, сопровождение и передача;
- матрицы ролей, требований, прослеживаемости и контрольные листы.
