# Android favourites, recent views and sharing 0.13.0

## Favourites

Server cards and guided scenario cards can be added to favourites with a long
press. Favourites are stored separately for every product and user role.

The dashboard includes a favourites-only filter. A filled star marks saved
cards.

## Recent views

The application stores the twenty most recently opened cards per role.
The `Недавние` section shows the card description, status and last-viewed time.

Recent views can be cleared without changing favourites or scenario progress.

## Sharing

Server cards and recently viewed cards can be shared through the standard
Android share sheet. Shared text includes the title, description, details and
product name.
