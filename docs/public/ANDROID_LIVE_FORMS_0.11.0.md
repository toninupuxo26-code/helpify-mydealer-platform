# Android live forms and data packs 0.11.0

## Forms

Server actions now use reusable Android forms with:

- required-field validation;
- text and multiline inputs;
- decimal and integer inputs;
- minimum numeric values;
- default values and field hints;
- explicit confirmation for state-changing actions.

## Helpify

Editable actions include:

- task creation;
- contractor offer creation;
- task chat messages.

Confirmed actions include offer selection and task completion.

Two data-pack actions support demonstrations:

- six varied customer tasks;
- offers for up to three open tasks.

## MyDealer

Editable actions include:

- product creation;
- cart quantity;
- order chat messages.

Confirmed actions include product publication, checkout and order state changes.

Two data-pack actions support demonstrations:

- six varied product cards;
- up to three published products added to the buyer cart.
