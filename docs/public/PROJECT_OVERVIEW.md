# Project overview

## Helpify

Helpify is a two-sided service marketplace.

### Customer capabilities

- registration and authentication;
- profile management;
- task creation;
- offer comparison;
- contractor selection;
- task status tracking;
- task chat;
- rating and history.

### Contractor capabilities

- registration and authentication;
- professional profile;
- service categories;
- access to open tasks;
- offer submission;
- task communication;
- task completion;
- rating and work history.

## MyDealer

MyDealer is a curated product marketplace.

### Buyer capabilities

- registration and authentication;
- catalogue browsing;
- product cards;
- persistent cart;
- checkout;
- order tracking;
- order chat;
- purchase history.

### Vendor capabilities

- registration and authentication;
- vendor profile;
- product management;
- moderation workflow;
- order processing;
- buyer communication;
- sales history.

## Shared platform capabilities

- REST API;
- role-based access control;
- MySQL persistence;
- Redis cache;
- web and Android clients;
- operational health checks;
- versioned deployment patches;
- technical and operational documentation.
