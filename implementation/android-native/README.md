# Native Android workspace

The workspace contains two Android applications and one shared core library.

- `helpify` — customer and contractor application;
- `mydealer` — buyer and vendor application;
- `core` — HTTPS API client, Bearer session storage and shared authentication/dashboard UI.

## 2021 technology profile

- Kotlin 1.5.31;
- Android Gradle Plugin 7.0.4;
- Gradle 7.0.2;
- compileSdk/targetSdk 31;
- minSdk 23;
- Java 11;
- AndroidX AppCompat 1.4.0;
- Material Components 1.4.0;
- classic Android View System.

The source release does not contain signing keys or production credentials.
