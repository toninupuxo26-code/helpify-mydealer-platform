# Helpify backend

This directory contains the implemented Laravel 8 API for Helpify.

Implemented patches:

- `3010`: PHP 7.4 / Laravel 8 runtime, MySQL 8, Redis 6 and health endpoints;
- `3020`: registration, login, bearer tokens, logout and test password recovery;
- `3040`: tasks, contractor offers, task status transitions and participant chat.

The implementation uses test demo data and is not represented as original
historical source code.
