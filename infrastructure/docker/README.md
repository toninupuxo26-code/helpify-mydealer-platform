# Docker profiles

- `era` — версии, характерные для 2021 года, используется в изолированной разработки;
- `public-demo` — защищенный внешний контур с документированными совместимостными мерами;
- `store-current` — сборочное окружение для актуальных SDK магазинов приложений.

Файл `docker-compose.era.example.yml` является только стартовой заготовкой и не предназначен для публичного production без hardening.
